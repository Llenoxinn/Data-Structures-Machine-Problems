# Data Structures Topic Hub & Companion Repositories

Later coursework topics (**Heaps** and **Hashing**) grew into dedicated study repositories with class notes, from-scratch C++ implementations, and LeetCode-style problem playbooks. This directory connects the main [`Data-Structures-Machine-Problems`](../README.md) repository to those companion repos so all DSA coursework materials stay navigable from one place.
